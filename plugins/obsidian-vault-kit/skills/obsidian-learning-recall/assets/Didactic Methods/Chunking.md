# Chunking

Splitting material into a few small, named pieces.

## Why it helps
Working memory holds only a handful of things at once. Small named chunks fit, and each name becomes a handle for recall.

## Where this vault uses it
"The idea" is 3-5 short chunks, each under its own heading.

## Try it
Name the chunks of today's note from memory, in order.

## How well supported
The limited capacity of working memory is well established (around four chunks in Cowan's 2001 estimate). Chunking as a study layout is a sensible application of it rather than a separately tested technique. This is a plain summary of the research, not a literature review; ask for sources if you want to read further.
