# Progressive disclosure

Showing the essentials first and keeping the depth one step away, so you choose how far to go.

## Why it helps
It lowers the effort of starting: a one-minute read is easy to begin, and the rest is there when you want it.

## Where this vault uses it
Only "Start here" is required reading; everything below it is optional depth, and check-yourself answers sit inside toggles.

## Try it
On a tired day, read just the Start-here boxes of today's due notes. That still counts.

## How well supported
A principle from interface design rather than a learning-research finding. It supports learning indirectly by reducing load and making starting easier. This is a plain summary of the research, not a literature review; ask for sources if you want to read further.
