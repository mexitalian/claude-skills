# Advance organizer

A short overview given before the details, so the new material has a frame to hang on.

## Why it helps
Knowing the shape of the whole makes each detail easier to place and remember.

## Where this vault uses it
The "Start here (1 minute)" box: takeaway, 3-5 bullets, "Do this next".

## Try it
Read only the Start-here box of a note, then say what you expect the rest to cover.

## How well supported
Introduced by Ausubel (1960). Effects in reviews are positive but modest; they are larger when the material is new and complex. This is a plain summary of the research, not a literature review; ask for sources if you want to read further.
