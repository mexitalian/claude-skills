# Dual coding

Pairing words with a simple picture of the same idea, such as a flowchart or a table.

## Why it helps
Words and images are processed in partly separate ways, so two linked versions give two routes back to the memory.

## Where this vault uses it
The small Mermaid diagram in "Picture it".

## Try it
Close the note and sketch the diagram from memory in ten seconds.

## How well supported
Based on Paivio's dual coding theory and Mayer's research on multimedia learning: words plus relevant pictures beat words alone. Decorative pictures do not help. This is a plain summary of the research, not a literature review; ask for sources if you want to read further.
