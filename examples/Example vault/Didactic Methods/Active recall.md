# Active recall

Pulling an answer out of memory instead of re-reading it.

## Why it helps
Each successful retrieval strengthens the memory far more than another look at the page does.

## Where this vault uses it
"Check yourself" (answer first, then open the toggle) and the Cards.

## Try it
Cover the note and write down the three main points. Then check.

## How well supported
One of the best-supported techniques in learning research (the testing effect), for example Roediger and Karpicke (2006). Rated high utility in Dunlosky and colleagues' 2013 review. This is a plain summary of the research, not a literature review; ask for sources if you want to read further.
