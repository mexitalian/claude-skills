# Implementation intentions

Turning an intention into a when-where-what plan: "When X happens, I will do Y".

## Why it helps
It hands the decision to a cue in your day, so the action happens without needing fresh willpower.

## Where this vault uses it
Each note's Actions: concrete checkboxes, including the rating step.

## Try it
Rewrite one action as "After [cue], I will [action] at [place]".

## How well supported
Gollwitzer and Sheeran's 2006 meta-analysis found a medium-to-large effect on reaching goals. The evidence is about doing things, not about memory itself. This is a plain summary of the research, not a literature review; ask for sources if you want to read further.
