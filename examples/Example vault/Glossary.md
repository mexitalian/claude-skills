# Glossary

Terms that keep coming up, in plain words. One `###` heading per term.

### Registration certificate
**Meaning:** the letter the registration office sends to confirm your new address. **Shows up in:** [[Register new address]].

### Snapshot
**Meaning:** a saved, point-in-time copy of a folder that a backup tool can restore. **Shows up in:** [[Home server backups]].
